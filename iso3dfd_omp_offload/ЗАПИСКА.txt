Инструмент командной строки Intel(R) VTune(TM) Profiler
Авторское право (C) 2009 корпорация Intel. Все права защищены.

 Использование: vtune <-action> [-action-option] [-global-option] [[--] target [target options]]

 Для получения справки по конкретному действию введите 'vtune -help <action>'.


Доступные действия:

    collect        Выберите тип анализа.
    collect-with   Выберите сборщик данных.
    command        Отправьте команду в процессе сбора данных.
    finalize       Повторно завершите сбор данных.
    help           Выведите текст справки.
    import         Создайте каталог для результатов, импортировав один или несколько устаревших файлов/каталогов с данными.
    report         Создайте отчет с указанным именем.
    version        Выведите версию продукта.


Дополнительные инструменты:

    Снимок производительности приложения

       Используйте Снимок производительности приложения для профилирования приложений на основе MPI и получения данных о производительности, специфичных для MPI.
       Введите aps --help, чтобы просмотреть соответствующие параметры.

    Сервер VTune Profiler

       Используйте VTune Profiler Server для просмотра собранных результатов в веб-браузере, что обеспечивает более удобный пользовательский интерфейс по сравнению с VNC или X-forwarding.
       Введите vtune-backend --data-directory=/path/to/folder/with/collected/results.

    Скрипт самопроверки

       Этот скрипт проверяет, правильно ли установлен VTune Profiler, и гарантирует, что он готов к использованию.
       Введите vtune-self-checker.sh, чтобы запустить этот скрипт.


Примеры:

 1) Начните со снимка производительности. Получите краткий обзор потенциальных проблем с производительностью. Определите дальнейшие шаги для более глубокого анализа:

    vtune -collect performance-snapshot iso3dfd

 2) Запустите сбор данных о «горячих точках» (с выборкой в пользовательском режиме) на указанном целевом устройстве:

    vtune -collect hotspots a.out

 3) Запустите сбор данных о «горячих точках» (с выборкой на основе аппаратных событий) с нестандартным интервалом выборки 0,5 мс:

    vtune -collect hotspots -knob sampling-mode=hw -knob sampling-interval=0.5 a.out

 4) Сформируйте отчёт о «горячих точках» для каталога результатов r000hs:

    vtune -report hotspots -r r000hs

 5) Запустите анализ микроархитектуры от имени пользователя vtune_user на удалённом целевом устройстве с IP-адресом 192.0.2.0:

    vtune -target-system ssh:vtune_user@192.0.2.0 -collect uarch-exploration a.out

 6) Профилирование системы с анализом доступа к памяти в течение 20 секунд:

    vtune -collect memory-access -d 20

 7) Запуск сбора данных о «горячих точках» графического процессора для процесса с идентификатором PID 1234:

    vtune -collect gpu-hotspots -target-pid 1234

 8) Запуск анализа производительности высокопроизводительных вычислений для MPI-приложения a.out, запущенного с помощью Intel MPI Launcher:

    mpirun -n 48 -ppn 24 vtune -collect hpc-performance -data-limit=0 -r my_result_dir a.out

 9) Показать параметры команды collect:

    vtune -help collect

 10) Показать параметры анализа многопоточности:

    vtune -help collect threading
